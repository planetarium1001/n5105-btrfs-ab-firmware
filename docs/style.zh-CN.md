# 文档风格

**中文** | [English](style.md)

有人只读一遍，而且读得很急，凭这一遍决定要不要信这一页。这些规则让这一遍变便宜。
`scripts/check_docs_style.py` 逐条测量下面的规则；`python3 scripts/check_design.py docs-style`
把它和其它设计检查一起跑。

## 页面成对

- 每个英文页旁边都有一个 `*.zh-CN.md` 译本。
- 两页的章节相同，顺序也相同。
- 检查器逐条比对标题层级，章节错位就失败。
- 只有文字不同；一边加了章节，另一边也要加。

## 限制

| 规则 | 限制 | 它保什么 |
|---|---|---|
| 段落 | 400 字符且 4 句 | 一屏一个论点 |
| 英文句 | 40 词 | 一口气读完的句子 |
| 中文句 | 80 字符，不计空格 | 同样一口气，按字符数 |
| 列表项 | 240 字符 | 一项一个事实 |
| 标题 | 80 字符 | 标题，不是摘要 |

- 表格不受段落规则约束；单元格可以长。
- 这些数字是检查器的默认值，不是建议。

## 正文

- 一句一个事实。装了两件事的句子要拆开。
- 一段一个论点。要加第五句时，另起一段。
- 并列的事实、命令与选项用 `-` 列表。
- 页面要比较三件以上的东西时，改用表格。
- 命令、数字、文件名与引用输出原样保留。
- 引用块也是正文，按段落测量。

## 块级排版

- 每个标题、每张表、每个围栏前后各留一个空行。
- 每个围栏都要标语言：`sh`、`text`、`json` 或真实的那一种。
- 每张表都要有表头行与分隔行。
- 每页只有一个 `#`，且标题层级不跳级。
- 列表项里的围栏可以紧贴列表项文字的前后。
- 写相对链接；每个链接都要能从所在页面解析到。

## 检查器跳过什么

规则只测量正文。下面这些不是正文，长度规则会跳过它们：

- 围栏代码块里的文本
- 表格行里的文本
- HTML 注释
- frontmatter
- 只有链接的一行

一个例外：表格行里的链接照样要检查，因为坏链接放在哪里都是坏链接。

## 本地运行

```sh
python3 scripts/check_docs_style.py                 # docs/ 下全部页面
python3 scripts/check_docs_style.py --report-only docs
python3 scripts/check_docs_style.py docs/style.md
python3 scripts/check_design.py docs-style
```

- 违规打印成 `path:line: message`，退出码 1。
- `--report-only` 打印同样的行，退出码 0。
- `check_design.py docs-style` 覆盖 `docs/` 以及它之外的四个 README。
- 句子在 `。！？；` 处结束，或在「`.` `!` `?` + 空格 + 大写字母」处结束。
- 两个风格页就是样板：在这两页上失败的规则，就是坏规则。

## 选项

| 选项 | 默认 | 作用 |
|---|---|---|
| `--max-paragraph` | 400 | 一个段落的字符上限 |
| `--max-sentence-words` | 40 | 一个英文句的词数上限 |
| `--max-sentence-chars` | 80 | 一个中文句的字符上限 |
| `--max-item` | 240 | 一个列表项的字符上限 |
| `--max-heading` | 80 | 一个标题的字符上限 |
| `--root` | 当前检出 | 相对路径的基准 |
| `--report-only` | 关 | 打印违规，退出 0 |

## 页面失败时

- 改页面，不改阈值。
- 在自然边界处拆开段落、句子或列表项。
- 重跑同一条命令，直到它报告这一页是干净的。
